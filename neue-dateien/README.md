# Neue Dateien

Dieser Ordner ist der gemeinsame Eingang für neue Dateien von Stephan.

Bitte neue Modelle und zugehörige Dateien zunächst hier hochladen. Sie werden anschließend geprüft und in die passende endgültige Projektstruktur verschoben.

Vorhandene Dateien in den anderen Modellordnern dabei nicht überschreiben oder löschen.

## Noch nicht verwendbar

`nicht-verwendbar/Arbeitsplatten.glb` ist nur 412 Byte groß und enthält keine Geometrie. Die Arbeitsplatten werden auf der Website deshalb weiterhin passend zur Konfiguration erzeugt. Für einen späteren Austausch muss diese Datei aus Blender mit sichtbarer Geometrie neu exportiert werden.
