1. RESPONSIVE DESIGN AUDIT

Check and optimize every public page and reusable component for:

* Desktop
* Laptop
* Tablet
* Smartphone
* Small smartphone screens

Test the layouts at common responsive breakpoints and also make sure the design works smoothly between breakpoints.

Fix:

* Horizontal overflow
* Elements extending outside the viewport
* Overlapping elements
* Broken grids
* Awkward wrapping
* Excessive empty space
* Sections that become too compressed
* Sections that become unnecessarily tall
* Inconsistent responsive behavior

The website should feel intentionally designed for every screen size, not simply scaled down from desktop.

2. MOBILE NAVIGATION

Thoroughly check the mobile navigation.

Ensure:

* The mobile menu is easy to open and close.
* Navigation items are clearly readable.
* Touch targets are large enough.
* Menu items have sufficient spacing.
* Nothing overlaps with the logo or other controls.
* The menu works correctly on narrow screens.
* The header does not take up excessive vertical space.
* The mobile navigation visually matches the desktop navigation.
* Important navigation elements remain easy to find.
* Language switching and other header controls remain usable if present.

3. BUTTONS AND INTERACTIVE ELEMENTS

Review all buttons, links, form controls, and interactive elements.

Ensure:

* Buttons are large enough for comfortable touch interaction.
* Mobile touch targets are approximately 44px minimum where appropriate.
* Button labels never get cut off.
* Text remains vertically and horizontally centered.
* Buttons do not become unnecessarily wide or narrow.
* Primary, secondary, and text buttons have clearly defined and consistent styles.
* Border radius, padding, font weight, and height are consistent.
* Hover, focus, active, and disabled states are visually coherent.
* Buttons do not unexpectedly wrap onto multiple lines.
* CTA buttons remain visually prominent without being oversized.

Use the same button system throughout the entire website.

4. TEXT AND TYPOGRAPHY

Check every page for typography problems.

Fix:

* Cut-off text
* Overflowing text
* Unwanted line breaks
* Headings that are too large on mobile
* Text that is too small to read comfortably
* Inconsistent heading sizes
* Inconsistent line heights
* Inconsistent font weights
* Poor spacing between headings and paragraphs

Create and enforce a consistent responsive typography hierarchy for:

* H1
* H2
* H3
* H4
* Body text
* Small text
* Labels
* Navigation
* Buttons

Use responsive font sizing where appropriate.

Large desktop headlines should scale down naturally on tablet and mobile instead of breaking the layout.

5. IMAGES AND MEDIA

Check every image across the website.

Ensure:

* Images scale correctly at every viewport size.
* Images maintain the correct aspect ratio.
* Images are never stretched or distorted.
* Images do not overflow their containers.
* Important image content is not accidentally cropped.
* object-fit and object-position are used appropriately.
* Image cards maintain consistent proportions.
* Large images do not create excessive page height on mobile.
* Images load into visually stable containers to avoid layout shifts.

6. FORMS

Review all forms visually across desktop, tablet, and mobile.

Ensure:

* Input fields are large enough.
* Labels are clearly associated with fields.
* Fields have consistent heights.
* Textareas scale correctly.
* Form layouts stack correctly on mobile.
* Fields never extend outside the viewport.
* Buttons remain easily accessible.
* Required states, error states, focus states, and success states have consistent styling.
* Spacing between fields is consistent.
* Forms look professional and trustworthy.

Do not change backend logic or form functionality unless necessary to fix a visual or responsive issue.

* Be visually identical across all public pages.
* Use the same height.
* Use the same logo size.
* Use the same horizontal padding.
* Use the same navigation spacing.
* Use the same typography.
* Use the same button styles.
* Behave consistently when scrolling.
* Use the same responsive behavior.
